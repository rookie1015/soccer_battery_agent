# v0.4.0 发布记录

## 核心模型

- 市场赔率成为概率基准，基本面和 Dixon-Coles 改为受限残差修正。
- 基本面输入按来源、覆盖情况和数据质量折算可靠度。
- 基本面内部系数可从严格赛前历史中滚动训练，但只生成候选模型。
- 低质量状态兜底不再作为独立数学证据重复计权。

## 风险与预算

- 三选保护先于证据第二选项。
- 输出预算利用率、未使用预算以及被预算移除的平局数量。
- 非矩形线路继续作为实验能力保留，未经样本外门禁不自动替换生产矩形票。

## 发布安全

- 复盘自动刷新候选报告，但不会自动修改生产参数。
- 只有严格赛前、按期 walk-forward 候选同时超过生产和纯赔率基线后，才具备人工晋升资格。
