- 生产模型升级为 `market-residual-1x2-v5`。
- 统一市场、基本面和数学证据的归属，投注取舍直接使用最终综合概率，避免重复计权。

- 预测和移动 API 增加平局校准特征、可用性、逐项贡献、修正和证据审计。
