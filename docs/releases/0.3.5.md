# v0.3.5 发布记录

发布日期：2026-08-23

## 修复

- Android 连接 DBpedia 球队别名服务超时时，不再中止完整分析。
- DBpedia 作为可选增强源失败后，分析继续使用内置别名和赛程上下文匹配。
- App 在本机保留最近一次 Python 分析异常堆栈，便于开发诊断。
- 修复将预算内独立单式线路的赛果并集误显示为一张低价复式票的问题。
- 14 场实际出票改为正规复式：各场预算票面选择数相乘，再按每注 2 元计算成本。
- 模型建议与实际预算票面继续分开显示，只有预算票面参与出票计价。
- 任九改为独立联合优化：共享基础概率，但单独选择 9 场及每场单选、双选或全包票面。
- 任九使用独立正规复式计价和独立预算上限；与十四场同时购买时，两项金额需要相加。
- 历史报告和复盘按任九独立票面恢复与统计，不再使用十四场预算票面代替任九结果。
- 修复球队身份仅凭联赛和开球时间猜测主客方向，导致别名与供应商 ID 交叉污染的问题。
- 修复主源赔率与期次专属辅助赔率呈主客镜像时仍继续使用错误方向的问题；镜像会自动纠正，其他严重冲突会切换到核验赔率。
- 自动清理旧身份库中与内置核验身份冲突的 kickoff-only 别名，本次已移除“巴黎=Rennes、雷恩=PSG”的错误映射。
