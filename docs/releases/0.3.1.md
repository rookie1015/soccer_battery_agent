# v0.3.1 发布与回退记录

发布日期：2026-08-22

## 版本边界

- `v0.3.0`：市场锚定与战术单平，Android versionCode 6。
- `v0.3.1`：预算内主票与平局对冲，Android versionCode 7。
- 发布时为两个版本分别建立 Git 标签；不要用未标记的工作目录猜测版本边界。

## 策略变更

1. `build_ticket_plan` 不再调用 `_apply_tactical_draw_strategy`，因此不会在预算优化前把整场推荐改成单选平。
2. 先按完整预算检查主票是否因压缩删除平局；存在候选时，80% 预算用于主票，最多 20% 用于一个独立对冲分支。
3. 对冲候选必须满足：模型原始选择含平、主票不含平、模型平局不低于 27%、市场平局不低于 25%、平局与最高概率差不超过 12 个百分点，并获得市场结构、可信数学层或有效赛前结构支持。
4. 对冲分支固定候选为 `1`，其余13场独立压缩；主票与对冲分支的实际成本相加不得超过用户预算。
5. 没有候选或预算低于10元时，不保留对冲预算，继续使用完整预算主票。

## 新增数据字段

- `TicketPlan.draw_hedge`：对冲场次、完整14场分支、分配预算、注数、实际成本、评分和依据。
- API `budget`：预算上限、主票分配/实际成本、对冲分配/实际成本和组合总成本。
- API `draw_hedge`：候选、票面和复盘结果；旧客户端可忽略该可选字段。
- 复盘记录候选单平是否命中、分支覆盖场数以及整个分支是否覆盖全部彩果。

## 回退方法

推荐先保留当前分支，再从标签建立回退分支：

```powershell
git switch -c rollback/0.3.0 v0.3.0
```

这会回到完整的0.3.0源代码，不需要手工逐文件撤销。回到0.3.1：

```powershell
git switch android
```

Android 已安装0.3.1时，直接安装versionCode 6通常会被系统拒绝降级。调试签名一致时可使用：

```powershell
adb install -r -d football-lottery-agent-v0.3.0-debug.apk
```

执行App降级前应先确认本机历史文件已有备份；不要通过卸载App来降级，否则可能清除应用私有数据。
