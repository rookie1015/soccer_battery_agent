# v0.3.3 发布与回退记录

发布日期：2026-08-22

## 修复内容

- v0.3.2 的新分析结果本身成本正确，但 Android 从历史列表重新解析 Markdown 时没有恢复独立线路组合，会用14场模型选择重新计算旧式矩形复式成本。
- 历史解析现在限定在“14场逐场建议”章节，并恢复预算、完整线路和平局配额字段。
- 26109 的1000元历史报告由错误显示419904元修正为500条线路、1000元。

## 模拟器验收

- 模拟器：`Medium_Phone_API_36.1`
- 26109：500元与1000元两条记录均成功生成并保存。
- 26110：500元与1000元两条记录均成功生成并保存。
- 模拟器外网处于部分连接状态，在线采集无法完成；验收使用昨日完整赛前快照注入近期缓存，仍由 Android 内置 Python 引擎执行模型、线路生成、序列化、报告归档与历史恢复。
- 历史重新打开后必须显示独立线路实际成本，不得再显示矩形复式乘积。

## 版本与回退

- `v0.3.2`：多平独立线路组合，Android versionCode 8。
- `v0.3.3`：多平线路历史修复，Android versionCode 9。

回退源码：

```powershell
git switch -c rollback/0.3.2 v0.3.2
```

调试签名一致时，Android 降级可使用：

```powershell
adb install -r -d football-lottery-agent-v0.3.2-debug.apk
```
